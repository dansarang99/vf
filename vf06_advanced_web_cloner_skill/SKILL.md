# Advanced Web Cloner & E-Commerce CMS Master Pipeline (vf06)
## (웹사이트 1:1 역공학 복제, Firebase 하이브리드 DB, E-Commerce, 엔터프라이즈 CMS v2.0, Vercel 글로벌 배포 마스터 스킬)

> **기획 및 지식재산권자**: (AX)창업기술 이한규 대표  
> **공식 리포지토리**: `github.com/dansarang99/vf/vf06_advanced_web_cloner_skill`  
> **핵심 가치 제언 (Core Value Proposition)**:  
> 임의의 레퍼런스 웹사이트 또는 프레젠테이션(PPTX)을 입력받아 **디자인 시스템, 인터랙션 미학, 데이터 구조를 100% 텍스트 청사진으로 역공학 추출**하고, **Firebase & Supabase 하이브리드 클라우드 DB**, **10,000원 단위 정렬 E-Commerce 풀스택(장바구니/주문/보증서)**, **엔터프라이즈 관리자 CMS 스튜디오 v2.0**, **스텔스 보안 핫스팟 및 Fast-Pass 인증**, **Vercel 글로벌 CDN 실서버 원클릭 배포**, **Playwright 0-Error 검증 및 [001]~[999] 결과물 순차 보존**을 단 한 번의 단절 없이 엔드투엔드로 완결하는 최고급 웹 클로닝 마스터 파이프라인입니다.

## 1. 7대 마스터 파이프라인 아키텍처 (7-Stage Master Architecture)

```

└────────────────────────────────────────────────────────────────────────┘
          │
          ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [제2단계] Firebase & Supabase 하이브리드 DB 듀얼 엔진 구축 (Database) │

          ▼
```

## 2. Vercel 배포 표준 규격 (`vercel/`)
모든 Vercel 배포 산출물은 `vercel/` 디렉토리에 정형화하여 영구 보존한다:
1. `vercel/url.txt`:
   - 공식 라이브 웹사이트 URL
   - 관리자 CMS 접속 URL
2. `vercel/deploy_info.json`:
   - 프로젝트명, 타겟, 상태, 배포 타임스탬프, 인스펙터 URL, 관리자 보안 계정
3. `vercel/README.md`:
   - 서비스 개요 및 원클릭 재배포(`npx vercel deploy --prod --yes`) 가이드

## 3. 엄격 가격 정책 (Strict 10,000 KRW Alignment Policy)
- 대한민국 미술품 및 이커머스 표준 정책에 따라, 모든 작품 가격, 장바구니 소계, 총 결제 금액, 가중치 조정 결과는 반드시 **최소 10,000원 단위**로 자동 반올림 정렬되어야 한다:
```javascript
const alignedPrice = Math.round(Number(rawPrice) / 10000) * 10000;
```

## 4. 원본 보존 및 [001]~[999] 결과물 이력 규칙
1. `vf01_webclone`은 초기 1단계 정적 아카이브 상태로 100% 무결 보존한다 (절대 수정 금지).
2. 모든 고도화 작업 및 E-Commerce/CMS 결과물은 `vf06_advanced_web_cloner_skill`에 독립 기록한다.
3. 모든 검증 스크린샷 및 마스터 보고서는 `result/`에 `[001]` ~ `[999]` 번호 체계로 누락 및 중복 없이 순차 기록한다.
