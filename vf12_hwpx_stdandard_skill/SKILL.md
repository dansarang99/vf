> **비장의 무기**: 『모달 연동 제로토발 (Zero-Token, Zero-Heat)』 체계 및 OXML 1:1 외과수술 복제 엔진

## 1. 개요 및 역사적 상징성 (Historical Milestone)

본 스킬은 2026년 4월 대한민국 정부(국가인공지능전략위원회, 행정안전부, 문화체육관광부)가 전 공무원 사회의 폐쇄형 HWP 첨부를 제한하고 개방형 HWPX로 전면 전환하기 위해 배포한 **역사적 상징 공문(보도자료)**을 100% 영구 표준 템플릿으로 공식 채택하여 개발된 **차세대 HWPX 변환 마스터 스킬**입니다.

기존의 마크다운 to HWPX 도구들이 범하는 고질적인 문제(빈 뼈대에 단순 텍스트를 복사-붙여넣기하여 정부 공문서의 품격이 증발하는 현상)를 원천 차단하고, 실제 대한민국 최고위 부처에서 결재·배포되는 **정부 표준 보도자료 및 공문서 양식을 1:1 외과수술 수준으로 완벽 복제**하여 모든 기획서, 보고서, 마크다운 문서를 최고급 공문서로 컴파일합니다.

## 3. 핵심 규칙 및 가이드라인 (Mandatory Rules)

1. **골든 템플릿 우선배치 원칙 (Template-First)**:
   - 빈 문서 템플릿(`Skeleton.hwpx`)에서 출발하는 것을 엄격히 금지하며, 반드시 패키지 내 [`templates/korea_government_standard.hwpx`](templates/korea_government_standard.hwpx)를 제1원본으로 로드하여 외과수술적 치환을 수행합니다.
2. **정부 엠블럼 및 OPC ZIP 무결성 사수**:
   - `BinData/image1.PNG` 등 바이너리 파트를 100% 보존하며, 생성되는 모든 `.hwpx`는 `mimetype`을 비압축(`STORE`) 첫 번째 엔트리로 기록합니다.
3. **공문서 개조식 위계 강제 (`□` -> `○` -> `(시사점)`)**:
   - 단순 `-` 불릿의 무분별한 나열을 금지하고, 대주제는 `□ 1.`, 세부항목은 `○`, 참고는 `※`, 시사점은 `○ (시사점)`으로 통일합니다.
4. **결과물 [001]~[999] 순차 시리얼 보존**:
   - 모든 변환 산출물은 `result/` 폴더에 3자리 일련번호를 부여하여 영구 보존합니다.

## 4. 원클릭 실행 커맨드 (Execution Guide)

### 파이썬 컴파일러를 통한 마크다운 to 정부 표준 HWPX 변환
```bash
python scripts/standard_hwpx_compiler.py <입력마크다운경로> -o <출력hwpx경로>
```

### 기본 예시 실행
```bash
python scripts/standard_hwpx_compiler.py "input_report.md" -o "result/[001]_정부표준_완제보고서.hwpx"
```

### 0-Error 무결성 전수 검증
```bash
python scripts/hwpx_qa_validator.py "result/[001]_정부표준_완제보고서.hwpx"
```
