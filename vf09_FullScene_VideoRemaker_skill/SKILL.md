# vf09-fullscene-video-remaker-skill : 2시간 풀씬 비디오 리메이커 마스터 스킬

본 스킬은 `vf08` 음성 역공학 자산과 `[204]` 심층 문제점 분석 결과를 기반으로 설계된 **초정밀 장편 영상(1~2시간) 리메이크 전용 스킬**입니다. 
유튜브 영상의 1,124개 씬 전수를 한 장면의 누락도 없이 캡처하고, 10대 보이스 캐릭터 1인 다역 오디오와 결합하여 **상영시간 오차율 0.3% 이내의 완벽한 리메이크 MP4 비디오**를 생산합니다.

---

## 1. 4대 코어 엔지니어링 규격

```
+-----------------------------------------------------------------------------------------+
|                  vf09 Full-Scene Video Remaker 4대 핵심 아키텍처                         |
+-----------------------------------------------------------------------------------------+
| 1. 상영시간 초단위 관리 (오차율 1% 이내) : 슬롯 간격 무음 프레임 주입으로 타임라인 드리프트 0% 통제 |
| 2. 10대 보이스 캐릭터 1인 다역 매핑   : 해설, 남주, 여주, 사령관, 악역, 모친, 친구, 소년, 라이벌, 기계 |
| 3. 풀씬 캡처 & 켄 번스(Ken-Burns)    : 씬별 타임코드 중심점 고화질 프레임 캡처 + 미세 줌인 연출 |
| 4. result/ [202]~[999] 무손실 보존   : 대본, 오디오, 캡처 에셋, 비디오 전수를 순차 번호로 페어링 보존 |
+-----------------------------------------------------------------------------------------+
```

## 2. 10대 배역 1인 다역 캐스팅 매트릭스

1. **[해설]** : 50대 남성 바리톤, 묵직한 서사 중심 (InJoonNeural, -2Hz, -7%)
2. **[주인공]** : 20대 후반 남성, 위기 극복형 에이스 (HyunsuNeural, +1Hz, +3%)
3. **[여주인공]** : 20대 중반 여성, 당차고 지적인 관제탑 엘리트 (SunHiNeural, +1Hz, -2%)
4. **[사령관]** : 60대 남성, 백전노장 장군 카리스마 (InJoonNeural, -5Hz, -12%)
5. **[악역]** : 30대 남성, 차갑고 날카로운 비아냥 (InJoonNeural, -3Hz, -1%)
6. **[어머니]** : 40-50대 여성, 자상하고 애절한 기도 (SunHiNeural, -3Hz, -8%)
7. **[친구]** : 20대 남성, 익살스럽고 능청스런 조력자 (HyunsuNeural, +4Hz, +10%)
8. **[소년]** : 10대 어린이, 순수하고 낭랑한 울먹임 (SunHiNeural, +5Hz, +8%)
9. **[라이벌녀]** : 20대 후반 여성, 냉철한 통계와 규정 엘리트 (SunHiNeural, +0Hz, +3%)
10. **[시스템]** : 기계/상황실, 절제된 비상 경보음 (InJoonNeural, +0Hz, +0%)

## 3. 엔드투엔드 실행 파이프라인

```bash
# 1. 1,124씬 10인 배역 마스터 대본 자동 생성 ([202])
python src/build_202_master_script.py

# 2. 2시간 10인 배역 오디오 타임라인 동기화 렌더링 ([203])
python src/render_vf09_2hour_multichar_timeline.py

# 3. 비디오 프레임 추출 및 MP4 리메이크 조립
python src/remake_video_builder.py --input-audio result/[203]_episode_01_2hour_multichar_master_voice.mp3
```
