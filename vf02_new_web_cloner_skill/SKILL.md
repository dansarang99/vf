# New Web Cloner & Presentation Master Pipeline (v2.0)
## (웹·슬라이드 1:1 역공학 복제, 1:N 분량 확장, 딥리서치, EDA 시각화 및 최종 슬라이드 합성 마스터 스킬)

> **기획 및 지식재산권자**: (AX)창업기술 이한규 대표  
> **공식 리포지토리**: `github.com/dansarang99/vf/vf02_new_web_cloner_skill`  
> **핵심 가치 제언 (Core Value Proposition)**:  
> 임의의 레퍼런스 PPTX 또는 웹사이트를 입력받아 **디자인 시스템, 색채 토큰, 인터랙션 미학, 데이터 구조를 100% 텍스트 청사진으로 역공학 추출**하고, 원본의 맥락을 토씨 하나 틀리지 않게 보존하면서 **1:N(2배~5배)으로 분량을 무손실 확장**한 뒤, **제미나이 딥리서치 원문**과 **공공데이터 20년차 EDA 시각화 차트(법적·통계적 인용구 완비)**를 적재적소에 결합하여 **100% 네이티브 파워포인트 완성본과 발표자 대본**을 완벽하게 산출하는 엔터프라이즈급 제작 파이프라인입니다.

## 1. 5대 핵심 파이프라인 아키텍처 (5-Stage Master Architecture)

```

         │
         ▼
┌────────────────────────────────────────────────────────────────────────┐

│  - STYLE.md        : 캔버스 배경, 서피스, 3대 액센트 컬러 토큰, 다크/라이트│
│  - UIUX.md         : 필 태그, 수직바, 인포그래픽 박스, 반응형 인터랙션  │
│  - DATA&EDA.md     : 수치 메트릭, KPI 배지, 도표/차트 구조 및 레이아웃 │
└────────────────────────────────────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [제2단계] 원문 보존 기반 1:N(2~5배) 분량증가 및 서사 확장 (Scaling Phase)│
│  - 원본 1:1 복제 내용 토씨 하나도 틀리지 않고 100% 보존                │
│  - 2배(40p➔80p), 3배(120p), 5배(200p) 계층적 서사 분기 프로토콜       │
│  - 매크로 맥락, 논리적 연결성, 기승전결 템플릿 라이브러리 자동 편찬   │
└────────────────────────────────────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [제3단계] 신규 주제 선정 및 제미나이 딥리서치 업로드 표준화 (Research) │
│  - 신규 비즈니스 주제 선정 및 Gemini Advanced / Deep Research 수행      │
│  - upload/ 폴더 표준 투입 규격: 딥리서치 PDF, 40p Master Script MD     │
│  - 자동 파싱 엔진(`stage3_ingest_research.py`)을 통한 정형 데이터화   │
└────────────────────────────────────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [제4단계] 공공데이터 크롤링, EDA 시각화 및 출처·인용 표준화 (EDA Phase)│
│  - 공공데이터포털, KEPCO, KMI, 한국은행, 통계청 공인 1차 데이터셋 수집 │
│  - 20년차 데이터 사이언티스트 EDA 분석 (기술통계, 상관분석, 가설검정)  │
│  - 300 DPI 초고화질 차트 생성 (White-Tech / Dark-Tech 디자인 매핑)     │
│  - 3대 인용표시 규정 엄수: [공식 1차 출처], [분석 모형], [법적 근거]   │

         ▼

│  - 3단계 딥리서치 서사 + 4단계 EDA 시각화 차트 적재적소(1:1) 매핑     │
│  - 100% 파워포인트 네이티브 벡터 도형 (이미지 통캡처 0% 완전 박멸)     │
```

## 2. 단계별 상세 실행 프로토콜

### [제1단계] 1:1 역공학 복제 및 5대 TEXT 청사진 추출 (Extraction Phase)

1. **입력 규격**:
   - 사용자가 분석하고자 하는 레퍼런스 PPTX 파일을 `upload/` 폴더에 저장합니다. (예: `upload/농촌재생_통합본(40쪽).pptx`)
2. **역공학 스캔 엔진 실행**:
   - `python scripts/stage1_extract_blueprints.py --input upload/농촌재생_통합본(40쪽).pptx --output result/`
3. **5대 TEXT 산출물 및 생성 규칙**:
   - **`businessDNA.md`**: 원본 발표 자료에 담긴 사업 모델의 철학, 타겟 고객, 가치 제언, 시장 내 해자(Moat)를 추출하여 텍스트로 보관.
   - **`DESIGN.md`**: 16:9 와이드스크린 규격(13.333" × 7.5"), 그리드 여백(상하좌우 마진), 7대 슬라이드 아키타입(표지, 목차, 챕터간지, 전략형, 2분할, 3카드, 간지/클로징), 계층적 타이포그래피 스케일(L1~L7 폰트 패밀리 및 크기).
   - **`STYLE.md`**: 캔버스 배경(예: 소프트 페일 민트 `#E4F8EC`), 서피스 카드(퓨어 화이트 `#FFFFFF`), 보더 라인(`#D1E7DD`), 3대 액센트 컬러(세룰리안 블루 `#0785C0`, 에메랄드 제이드 `#0D7C5B`, 앰버 골드 `#D97706`), 다크/라이트 모드 대응 토큰.
   - **`UIUX.md`**: 상단 브레드크럼 필 태그(Pill Tag), 좌측 액센트 바, 하단 익스큐티브 인사이트 카드, 푸터 메타데이터/페이지 카운터 등 인터랙션 구조 명세.
   - **`DATA&EDA.md`**: 슬라이드 내 포함된 수치 지표, KPI 배지, 표(Table), 차트의 시각적 형태 및 정량 데이터 포맷 명세.
4. **1:1 복제본 생성**:
   - 추출된 명세를 기반으로 원본과 100% 일치하는 네이티브 도형 1:1 복제본 PPTX를 빌드하여 보관합니다.

### [제2단계] 원문 보존 기반 1:N(2~5배) 분량증가 및 서사 확장 (Scaling Phase)

1. **원문 100% 보존 원칙 (Verbatim Context Retention)**:
   - 1:1로 복제된 원본 슬라이드의 제목, 본문 불릿, 발표자 대본의 어휘를 토씨 하나도 바꾸지 않고 100% 원문 그대로 유지합니다.
2. **1:N 맥락 확장 매트릭스**:
   - **1:2 확장 (40쪽 ➔ 80쪽)**: 각 전략 불릿(Bullet) 1개를 독립 슬라이드 1장으로 확장하여 상세 실행 아키텍처 및 세부 방법론 제시.
   - **1:3 확장 (40쪽 ➔ 120쪽)**: 방법론 슬라이드 뒤에 국내외 선진 사례 벤치마크, 기술적 비교 분석 및 정량 데이터 실증 슬라이드 추가.
   - **1:4 확장 (40쪽 ➔ 160쪽)**: 부처별 인허가, 법적 쟁점, 리스크 대응 매트릭스 및 재무적 타당성 시뮬레이션 슬라이드 심층 확장.
   - **1:5 확장 (40쪽 ➔ 200쪽)**: 10개년 로드맵, 소부장 생태계 수직계열화, 거시경제 유발효과 및 세부 실행 Action Plan 슬라이드 완비.
3. **서사 연속성 보장 (Contextual Narrative Cohesion)**:
   - 분량이 N배로 늘어나더라도 대주제(Chapter)와 소주제 간의 논리적 흐름이 끊기지 않도록 브릿지 슬라이드(간지)와 브레드크럼 네비게이션을 체계적으로 자동 생성합니다.

---

### [제3단계] 신규 주제 선정 및 제미나이 딥리서치 업로드 표준화 (Research Phase)

1. **딥리서치 표준 워크플로우**:
   - 신규 주제(예: 새만금 현대차 글로벌 피지컬 AI 로보틱스 메가팩토리)가 선정되면, 구글 제미나이(Gemini Advanced / Gemini Notebook)를 활용하여 심층 리서치를 수행합니다.
2. **`upload/` 폴더 표준 투입 규격**:
   - `(딥리서치)_신규주제_심층분석.pdf`: 정책 보고서, 학술 논문, 산업 리서치 원문.
   - `[012]_신규주제_40p_Master_Script.md`: 전체 슬라이드별 타이틀, 핵심 요약 불릿, 발표자 대본 전문.
   - `[013]_신규주제_Part1_Render_Prompt.md`: 전반부(1~20쪽) 시각화 연출 프롬프트.
   - `[014]_신규주제_Part2_Render_Prompt.md`: 후반부(21~40쪽) 시각화 연출 프롬프트.
3. **자동 데이터 정형화**:
   - `python scripts/stage3_ingest_research.py`를 실행하여 업로드된 딥리서치 문서를 파싱하고, 슬라이드 번호, 챕터, 타이틀, 본문 불릿, 발표자 대본을 `parsed_slides.json`으로 구조화합니다.

### [제4단계] 공공데이터 크롤링, EDA 시각화 및 출처·인용 표준화 (EDA Phase)

1. **공인 1차 원천 데이터 수집**:
   - 공공데이터포털(`data.go.kr`), 산업통상자원부, 국토교통부, 한국전력공사(KEPCO), 한국해양수산개발원(KMI), 한국은행, 국제로봇연맹(IFR) 등 공신력 있는 기관의 통계 수집.
2. **20년차 데이터 사이언티스트 EDA 분석 (`py-eda` 기준 준수)**:
   - 수치형 변수(평균, 사분위수, 왜도, 표준편차) 및 범주형 변수(고유값, 빈도수) 기술통계 산출.
   - 일변량(분포), 이변량(상관, 회귀), 다변량(교차표, 투입산출모형) 분석.
   - 각 통계표 및 차트에 대해 2,000자 이상의 통계적 해석과 비즈니스 인사이트 작성.
3. **300 DPI 초고화질 차트 시각화 (White-Tech / Dark-Tech 매핑)**:
   - 템플릿의 `STYLE.md` 토큰에 맞춰 차트 캔버스 배경(화이트 `#FFFFFF` 또는 다크 `#0B1120`), 세룰리안 블루, 에메랄드 제이드, 앰버 골드 컬러 매핑.
   - 해상도 3000 × 1500 (300 DPI) 고해상도 PNG 렌더링.
4. **엄격한 3대 인용표시 규정 (Strict Citation Rules)**:
   - 모든 시각화 차트 및 슬라이드에는 다음 3대 요소를 반드시 명기합니다:
     1. **`[공식 1차 출처]`**: 기관명, 보고서 공식 명칭, 발표 연도 (예: `Goldman Sachs Global Tech Analysis / IFR World Robotics 2024`)
     2. **`[분석 모형 / 방법론]`**: 적용된 수학적 모델 (예: `험프리-라이트 82% 학습 곡선 모델(Wright's Law)`, `한국은행 투입산출모형(I-O Model)`)
     3. **`[법적·표준 근거]`**: 관련 법률 조항 및 국제 규격 (예: `새만금사업법 제27조`, `산업융합촉진법 제24조`, `ISO 18646-1`)

---

### [제5단계] 최종 슬라이드 템플릿 통합 완성 및 납품 (Synthesis Phase)

1. **템플릿 선택 및 레이아웃 매핑**:
   - 1단계~2단계에서 생성된 템플릿 중 요구 분량(1:1 ~ 1:5)에 맞는 슬라이드 덱을 선택합니다.
2. **적재적소 1:1 주입 엔지니어링**:
   - 3단계 딥리서치 서사 텍스트와 4단계 EDA 시각화 차트를 주제 연관성이 완벽히 일치하는 슬라이드(적재적소)에 1:1 배치합니다.
   - 좌우 2분할 레이아웃: 좌측 전략 텍스트 카드 + 우측 화이트테크 차트 컨테이너 및 출처 박스.
3. **100% 순수 파워포인트 네이티브 벡터 구현**:
   - 파워포인트 내 모든 요소(배경, 카드, 텍스트 박스, 배지, 선)를 네이티브 Shape 객체로 생성하여 사용자가 텍스트, 폰트, 색상을 자유자재로 편집할 수 있도록 합니다. (전체 슬라이드 통이미지 캡처 0% 완전 배제)
4. **발표자 상세 대본(Notes Slide) 100% 완벽 탑재**:
   - 40장 전 슬라이드의 파워포인트 슬라이드 노트(Notes Slide)에 화면 요약 요점과 C-레벨 구두 발표용 전문 스크립트를 누락 없이 100% 수록합니다.
5. **단일 정수 연속 관리 번호 (`[001]` ~ `[999]`) 원칙**:
   - 생성되는 모든 산출물(데이터셋, 스크립트, 차트 압축팩, 명세서, PPTX 완성본, 인덱스)은 생성 순서대로 `[001]` ~ `[999]` 번호를 붙여 `result/`에 기록하며, 중복·누락·앞번호 덮어쓰기를 절대 금지합니다.

## 5. 안티패턴 및 품질 보증(QA) 수칙

1. **통이미지 슬라이드 캡처 절대 금지 (Zero Flat Slides)**: 슬라이드를 통째로 이미지로 캡처하여 붙여 넣지 말 것. 반드시 파워포인트 네이티브 Shape와 TextBox 객체로 렌더링해야 함.
2. **출처 없는 차트 금지 (Zero Uncited Charts)**: 모든 차트 하단에는 반드시 `[공식 1차 출처]`, `[분석 모형]`, `[법적/통계적 근거]`가 표기되어야 함.
3. **대본 누락 절대 금지 (100% Notes Retention)**: 40개 슬라이드 중 단 1개라도 슬라이드 노트(Notes Slide)가 비어 있어서는 안 됨.
4. **번호 중복 및 덮어쓰기 금지 (Strict Sequential Indexing)**: 새로운 버전이 나오더라도 이전 번호(`[001]`, `[022]`, `[029]`, `[035]`)를 덮어쓰지 말고 반드시 신규 번호(`[041]`, `[042]` 등)로 순차 누적할 것.
