## 3. /grill-me 2단계 기관 템플릿 연동 인터뷰 체크포인트

본부장님께서 말씀해주신 차기 단계(**"이후에 우리기관에서 사용하는 hwpx 템플릿을 줄테니 그 다음순서를 진행해줘"**)를 단 0.1초 만에 완벽히 맞춤형으로 수행하기 위한 핵심 사전 점검 체크리스트입니다:

### 📌 [Check 1] 템플릿 투입 방식
- 기관에서 사용 중인 양식 파일(예: `우리기관_보고서양식.hwpx`)을 `upload/` 폴더에 복사해 넣어주시면, 대장장이가 즉시 역공학 분석을 수행합니다.

### 📌 [Check 2] 기관 스타일 DNA 추출 항목
1. **용지 여백 및 단 설정**: 일반 A4 단일 단인지, 2단 기안문 형식인지 확인.
2. **기관 고유 폰트**: 휴먼명조, 한컴바탕, 나눔고딕, 고딕계열 등 기관 표준 글꼴.
3. **상단 기관 로고 및 머리말/꼬리말**: 상단 배너 이미지 유무, 결재란 표(담당-과장-국장-본부장) 유무.
4. **고유 번호 체계**: `1. -> 가. -> 1) -> 가) -> (1) -> (가)` 형태의 공문서 표준 개요 번호 체계 적용 여부.
