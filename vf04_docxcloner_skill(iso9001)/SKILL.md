# Enterprise DOCX 100% Surgical Cloner Master Pipeline (v3.0)
## (OOXML 무손실 보존, 전 페이지 머리글 네이티브 TEXT 치환, AX 문서번호 체계화 마스터 스킬)

> **기획 및 지식재산권자**: (AX)창업기술 이한규 대표  
> **공식 작업 공간**: `vf04_docxcloner_skill(iso9001)`  
> **핵심 가치 제언 (Core Value Proposition)**:  
> 엔터프라이즈 규격 문서를 복제할 때 강제로 끼워 넣은 티가 나는 조잡한 비트맵 이미지 치환을 철저히 배제하고, 원본 문서의 모든 여백, 스타일, 폰트, 자간, 장평, 줄간격을 **100.00% 보존(Zero-Drift)**하면서, 머리글 상단 셀과 표지 사명을 **워드 네이티브 일반 TEXT `(AX)창업기술`**로 자연스럽게 배치하며, 문서번호 체계 또한 **`NX-`에서 `AX-`**로 일괄 승계하여 마치 처음부터 작성된 완성형 정품 규격 문서를 산출하는 마스터 파이프라인입니다.

## 1. 5대 핵심 파이프라인 아키텍처

```
[입력: 레퍼런스 DOCX] (upload/ 폴더)
         │
         ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [제1단계] OPC 패키지 분해 및 서식 지문 추출 (Inspection & Fingerprinting) │
│  - zipfile 기반 OPC 패키지 구조 분석 ([Content_Types].xml, _rels, word/)  │
│  - document.xml, header*.xml, footer*.xml 텍스트 및 런(Run) 단편화 진단   │
│  - 머리글 표 셀 구조(폭 1,767 dxa, 4행 병합) 및 문서번호(NX-) 위치 매핑 │
└────────────────────────────────────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [제2단계] 네이티브 타이포그래피 정밀 설계 (Natural Typography Design)   │
│  - 인위적 이미지 비트맵을 완전 배제하고 워드 표준 XML 텍스트 런 설계    │
│  - 맑은 고딕 Bold 11pt, 셀 내 중앙 정렬, 줄간격 100% 유지              │
│  - 표지 상단 중복 드로잉 객체 제거 및 단일 텍스트 사명 정렬            │
└────────────────────────────────────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [제3단계] 외과수술적 사명 치환 및 AX- 문서번호 동기화 (Transfusion)     │
│  - (주)구글구글시스템즈 ➔ (AX)창업기술 문맥/조사(은/는) 완벽 정합 치환 │
│  - NX-QM-100 ➔ AX-QM-100, NX-QP-* ➔ AX-QP-*, 회사의 약자 NX ➔ AX       │
│  - 단락 속성(<w:pPr>), 글자 속성(<w:rPr>), twip 단위 서식 100% 보존     │
└────────────────────────────────────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [제4단계] 전 페이지 머리글/바닥글 동기화 및 패키징 (Repack Phase)       │
│  - 전체 68p 매뉴얼 및 201p 절차서 전 영역 머리글에 (AX)창업기술 반영    │
│  - 절차서 바닥글(footer1.xml) 사명 및 AX-QP- 문서번호 동시 마감         │
│  - ZIP_DEFLATED 알고리즘 기반 초경량/고정합성 무손실 재패키징           │
└────────────────────────────────────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [제5단계] [001]~[999] 순차 등록 및 이중 무결성 검증 (Audit & Delivery) │
│  - result/ 폴더 내 [001]부터 누락/중첩 없이 순차 파일명 부여            │
│  - MS Word COM Automation 기반 68p/201p 전수 0페이지 편차 검증 (PASS)    │
│  - PyMuPDF 기반 150 DPI 고해상도 PDF 및 검증 보고서 일괄 편찬 납품     │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. [001]~[999] 결과물 표준 대장

모든 산출물은 `result/` 폴더에 `[001]`부터 누락이나 중첩 없이 엄격하게 기록·보존됩니다.

```
result/
├── [001]_1.품질경영매뉴얼_(AX)창업기술_R1(2026).docx       # 매뉴얼 100% 복제 원본 (68p)
├── [002]_1.품질경영매뉴얼_(AX)창업기술_R1(2026).pdf        # 매뉴얼 전수 검증용 PDF (68p)
├── [003]_ISO9001_품질경영매뉴얼_100%무손실복제_검증보고서_(AX)창업기술.md # 매뉴얼 1:1 검증 보고서
├── [004]_2.품질경영시스템절차서_(AX)창업기술_R1(2026).docx     # 절차서 100% 복제 원본 (201p)
├── [005]_2.품질경영시스템절차서_(AX)창업기술_R1(2026).pdf      # 절차서 전수 검증용 PDF (201p)
├── [006]_ISO9001_품질경영시스템절차서_100%무손실복제_검증보고서_(AX)창업기술.md # 절차서 1:1 검증 보고서
└── [007]_ISO9001_문서화패키지_100%무손실복제_통합총괄대장_(AX)창업기술.md  # 전 269p 통합 총괄 대장
```
