## 2. 대본 작성 시 화자 태그(Tagging) 표준 문법

대본 작성 시 각 대사 줄 맨 앞에 `[배역명]` 또는 `[ID]`를 명시하면 엔진이 자동으로 감지하여 해당 캐릭터의 목소리로 스위칭 합성합니다:

```text
[해설] 비행기 우측 엔진에 거대한 화염이 치솟기 시작했습니다.
[시스템] 경고, 경고. 유압 시스템 압력 상실. 비상 착륙 모드로 전환하십시오.
[주인공] 관제탑, 들립니까? 제가 수동 조종으로 기수를 잡겠습니다!
[여주인공] 코드 블루 발령! 모든 활주로를 즉시 비우세요. 당신을 믿어요!
[사령관] 긴장하지 마라. 자네는 우리 공군 최고의 날개다.
[악역] 흥, 저 조종 불능 고철 덩어리를 착륙시키겠다고? 어디 한번 해보시지.
[친구] 야, 살아서 내려오면 내가 평생 치맥 쏜다! 제발 버텨라!
```

## 3. 듀얼 확장성 (향후 ElevenLabs 연동)
- 로컬 모드에서는 `Edge-TTS`의 다중 보이스 및 피치/속도 파라미터로 즉시 10인 배역을 구현합니다.
- 향후 ElevenLabs를 연동할 경우, `config.json`의 `CHARACTER_VOICE_IDS` 딕셔너리에 10개의 Voice ID를 등록하면 각 배역마다 실제 서로 다른 성우들의 1:1 목소리로 자동 승계 생성됩니다.
