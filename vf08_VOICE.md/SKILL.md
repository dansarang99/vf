# vf08-voice-cloner-skill : 10대 VOICE 캐릭터 다중 화자 드라마 & 보이스 클로너 마스터 스킬

본 스킬은 `github.com/dansarang99/vf/vf08_VOICE.md`에 구축된 **8대 음성 DNA 역공학 자산(`VOICE_MASTER.md`)** 및 **10대 VOICE 캐릭터 캐스팅 매트릭스(`[014]_VOICE_CHARACTER_ROSTER_10.md`)**를 기반으로 작동합니다.

---

## 1. 10대 VOICE 캐릭터 배역 매트릭스

1. **[해설 / NARRATOR]** : 50대 남성 바리톤, 신뢰감과 긴장감 (126Hz, -7% 속도)
2. **[주인공 / HERO]** : 20대 후반 남성, 패기 넘치는 열혈 에이스
3. **[관제사 / 여주인공 / HEROINE]** : 20대 중반 여성, 당차고 지적인 엘리트
4. **[사령관 / 장군 / MENTOR]** : 60대 남성, 묵직하고 느린 권위 (-5Hz, -12% 속도)
5. **[악역 / 라이벌 / VILLAIN]** : 30대 남성, 차갑고 날카로운 저음
6. **[어머니 / 조연여 / SUPPORT_F]** : 40-50대 여성, 포근하고 자상한 기도 톤
7. **[친구 / 조력자 / FRIEND]** : 20대 남성, 능청스럽고 유쾌한 빠른 템포 (+4Hz, +10% 속도)
8. **[소년 / 어린이 / CHILD]** : 10대 청소년/어린이, 낭랑하고 청명한 고음 (+5Hz, +8% 속도)
9. **[라이벌녀 / 엘리트 / RIVAL_F]** : 20대 후반 여성, 냉철하고 도도한 지적 톤
10. **[시스템 / 경보 / SYSTEM]** : 상황실 비상 방송 및 항공 시스템 기계음

---

## 2. 사용법 (다중 화자 시네마틱 드라마 생성)

### Step 1. 화자 태그 대본 작성
대본 파일에 각 대사마다 `[배역명]` 태그를 붙입니다:
```text
[해설] 시각은 오후 5시 42분. 거대한 폭음이 울렸습니다.
[주인공] 관제탑! 조종간이 먹통이다!
[관제사] 침착하세요! 15마일 지점에 활주로가 있습니다!
[사령관] 겁먹지 마라. 자네는 최고의 날개다.
```

### Step 2. 다중 화자 엔진 실행
```bash
python src/multi_char_tts_engine.py --file my_script.txt --name "my_drama"
```
*(실행 시 `result/[NNN]_my_drama_script.txt`와 `result/[NNN]_my_drama_voice.mp3`가 자동 생성되며, 10명의 배역 목소리가 매끄럽게 교차 합성됩니다.)*

---

## 3. result/ [001]~[999] 무손실 순차 보존 체계
모든 산출물은 `result/` 디렉터리에 `[001]`부터 `[999]`까지 순차 번호 접두어를 붙여 대본과 오디오가 1:1 페어로 영구 보존됩니다.
