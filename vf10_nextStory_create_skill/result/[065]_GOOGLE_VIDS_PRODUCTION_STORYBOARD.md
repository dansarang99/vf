# [065] 구글 Vids (Google Vids) 공식 임포트용 스토리보드 마스터팩

> **무손실 누적 보존(Zero-Overwrite Immutable Versioning) 원칙 적용**:
> 본 문서는 구글 Vids(Google Vids / Google Flow)에 단 한 번에 주입하여, 정지화면이 아닌 **수백만 개의 실제 움직이는 고화질 비디오 클립(Stock Moving Videos)**과 결합된 100% 진짜 동영상을 제작하기 위한 공식 스토리보드 규격서입니다.

---

## 1. 구글 Vids (vids.google.com) 사용 방법

1. 브라우저에서 **[Google Vids](https://vids.google)** 접속 (Google Workspace 또는 구글 계정).
2. **'새 동영상 만들기' (Create New Video)** 클릭.
3. **'AI로 시작하기' (Help me create a video)** 창에 본 문서의 **[프롬프트 총괄 요약]**을 붙여넣거나,
4. 아래의 **[씬별 스토리보드 테이블]**을 복사하여 Google Vids의 각 씬(Scene) 타임라인에 차례대로 배치합니다.
5. Google Vids가 자동으로 각 씬의 **비주얼 키워드에 맞는 실제 움직이는 비디오 클립(로켓 발사 실제 영상, 관제실에서 회의하는 실제 영상, 우주비행사 실제 조작 영상 등)**을 추천·배치해 줍니다!
6. 오디오는 우리가 이미 렌더링한 `result/[023]_episode_02_k_space_master_audio.mp3`를 배경 음악/보이스 트랙으로 업로드하여 결합하면 100% 완벽한 극장판 동영상이 완성됩니다.
