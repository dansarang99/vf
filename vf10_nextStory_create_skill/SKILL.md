## 🌟 1. 스킬 개요 및 기획 의도

`vf10-nextstory-create-skill`은 전작(에피소드 1)의 항공 구조 웹드라마를 **대한민국 우주항공청(KASA)의 공식 국가 우주개발 로드맵**과 결합하여, 대한민국 최초의 심우주 사령관 대서사시로 격상시키는 **차세대 영상 제작 마스터 파이프라인**입니다.

기존 상용 웹 툴(Google Vids, Runway, Pika, Kling 등)의 수작업 한계와 막대한 API 토큰 비용 문제를 **'로컬 자체 동영상 생성기(Self Moving Video Generator)'**와 **'3D 시네마틱 I2V 모션 엔진'**, 그리고 **'Ground-Truth 오디오 동기화 엔진'**으로 완벽하게 해결하여, **비용 $0, 토큰 0, 오차율 0.00%의 엔터프라이즈급 장편 시네마틱 비디오**를 자동으로 완성합니다.

## 🎬 4. 3D 시네마틱 I2V 모션 엔진 6대 연출 기법

정지된 단일 키프레임 이미지에 생명력을 불어넣는 6대 모션 프리셋:

```python
# 1. zoom_in   : 긴박한 대사, 결의, 중요 발견 씬 (1.00x -> 1.15x 부드러운 돌리-인)
# 2. zoom_out  : 웅장한 전경, 새로운 행성/위성 공개 (1.15x -> 1.00x 풀-아웃)
# 3. pan_left  : 좌측으로 흐르는 수평 트래킹 샷 (탐사선 횡단, 관제실 파노라마)
# 4. pan_right : 우측으로 흐르는 수평 트래킹 샷
# 5. tilt_up   : 하단에서 상단으로 솟구치는 틸트 업 (로켓 발사, 거대 외계 간헐천)
# 6. orbit_cw  : 시계방향 미세 회전 및 줌 복합 샷 (양자 AI 코어, 무중력 유영)
```

## 🛡️ 8. 0-Error 무결성 검증 기준

1. **FFmpeg 디코드 무결성**: `ffmpeg -v error -i [video] -f null -` 실행 시 에러 0건.
2. **Web FastStart 규격**: `moov atom`이 파일 헤더에 위치하여 웹 브라우저에서 버퍼링 없이 즉시 재생.
3. **오디오 샘플레이트 통일**: 전 클립 24,000Hz 단일 채널 표준화로 결합 시 틱(Tick) 노이즈 100% 방지.
4. **타임라인 오차 통제**: 전체 상영시간 누적 오차 0.05% 이내(실측 0.00% 달성).
5. **[001]~[999] 불변 보존**: 어떤 상황에서도 기존 파일 덮어쓰기 금지.
