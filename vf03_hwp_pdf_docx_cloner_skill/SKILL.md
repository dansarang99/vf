# vf03: HWP / PDF / DOCX 100% 무손실 크로스플랫폼 문서 복제 마스터 파이프라인

## 1. 개요 및 설계 철학
본 스킬은 공공기관 및 대기업, 중소기업에서 널리 쓰이는 **아래아한글(HWP)** 및 **PDF** 문서를 **마이크로소프트 워드(DOCX)**로 변환할 때 발생하는 표 깨짐, 폰트 뒤틀림, 여백 붕괴 및 페이지 수 증가(Page Drift) 현상을 0%로 완벽 차단하고, 토씨 하나 틀리지 않는 100% 무손실 복제를 달성하는 마스터 엔지니어링 파이프라인입니다.

```

┌──────────────────────────────────────────────────────────────┐
│  [Stage 1 & 2] 구조적 레이아웃 & 테이블 역공학 중간체 생성   │
└──────────────────────────────┬───────────────────────────────┘
                               │
                               ▼
┌──────────────────────────────────────────────────────────────┐
│  [Stage 3] OOXML 외과수술 침습 치환 (Surgical Transfusion)  │
│  - 사명 치환: (주)구글구글시스템즈 ➔ (AX)창업기술             │
│  - 머리글 로고 drawing 박멸 ➔ 네이티브 일반 TEXT 치환        │

│  [Stage 4] Zero-Drift 정밀 캘리브레이션                      │

│  - 섹션 상하 여백 미세 최적화 (top=200, bottom=350)          │

│  - [001]~[999] 결과물 순차 대장 등록 및 무결성 보고서 편찬   │
```

## 3. 핵심 규칙 및 가이드라인

1. **사명 및 브랜드 표기**:
   - 변경된 사명은 반드시 **`(AX)창업기술`**로 일괄 적용합니다.
   - 머리글의 로고 영역은 인위적인 이미지 삽입 흔적을 완전히 배제하고, 워드 기본 일반 TEXT(`<w:t>(AX)창업기술</w:t>`)로 자연스럽게 서식화합니다.
2. **문서번호 일괄 동기화**:
   - 원본 접두어(`NX-`)를 새 접두어(`AX-`)로 전수 치환합니다 (예: `NX-QM-100` ➔ `AX-QM-100`).
3. **페이지 수 100% 일치 (Zero-Drift)**:
   - 원본 문서의 총 페이지 수와 변환 복제본의 실제 MS Word 렌더링 페이지 수가 0.01%의 편차도 없이 완벽히 일치해야 합니다.
4. **결과물 명명 및 보존 규정**:
   - 모든 결과물은 `[001]`부터 `[999]`까지 누락이나 중첩 없이 순차 번호를 부여하여 `result/` 폴더에 영구 보존합니다.
