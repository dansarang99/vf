## 1. 3대 핵심 결함 극복 및 `@docx` / `@doc-coauthoring` 통합 원리

본 스킬은 기존 변환 툴들이 범하는 3대 고질적 결함(페이지 폭발, 표 중첩, 가짜 개체 침투)을 `@docx`와 `@doc-coauthoring`의 핵심 기법을 흡수하여 원천적으로 해결합니다:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                        vf15-hwp-remocon 통합 엔지니어링 메커니즘                        │
├──────────────────────────┬─────────────────────────────────────────────────────────────┤
│ 1. 표 중첩 0% 완전 박멸   │ • @docx 듀얼 너비 원칙: 표 전체 너비 및 모든 셀 폭 DXA 일치   │
│    (Zero-Overlap)        │ • Hancom TreatAsChar=1 (글자처럼 취급) 강제 전환으로 부유 차단 │
│                          │ • 가용 본문 폭(139.3mm / 39,486 HU) 초과 와이드 표 비례 축소│
├──────────────────────────┼─────────────────────────────────────────────────────────────┤
│ 2. Zero-Drift 100% 페이지 │ • 단일 set_pagedef 일괄 덮어쓰기 금지 (구역별 실측 여백 보존) │
│    (Page Drift 0%)       │ • 2단 다단 구역 sectPr의 type="continuous" 정상화로 분할 차단 │
│                          │ • 셀 내부 상하 여백 0pt 및 줄간격 8.5~9.5pt 슬림화 캘리브레이션│
├──────────────────────────┼─────────────────────────────────────────────────────────────┤
│ 3. 외과수술적 개체 정제   │ • @docx merge_runs 기법: 잘게 쪼개진 런을 병합하여 검색성 확보│
│    (Ghost Cleanse)       │ • 가짜 소제목 1x2 표 8건 ➔ 네이티브 일반 문단으로 환원         │
│                          │ • 본문 침투 가짜 푸터 60건 정규식 전수 척결 ➔ sec.Footers 이관 │

├──────────────────────────┼─────────────────────────────────────────────────────────────┤
│ 4. 협업 및 검증 프로토콜 │ • @doc-coauthoring 3단계: 컨텍스트 수집 ➔ 공동 구조화 ➔ 검증 │
│    (Co-Author & Vision)  │ • /grill-me 대화형 승인 게이트 (ask_question)                │
│                          │ • PyMuPDF 300 DPI 래스터라이징 & Multimodal VisionCheck 공인 │
└──────────────────────────┴─────────────────────────────────────────────────────────────┘
```

## 2. 2단계 거대 아키텍처 (Two-Stage Master Architecture)

```
========================================================================================
[1단계: 사문화된 PDF ➔ 100% 무손실 살아있는 문서 복제 (Zero-Drift Cloning)]
  ├─ Step 1. [DNA.md] 20대 코어 청사진 사전 정밀 계측 (판형, 폰트, 여백, 표, 차트, 각주)
  ├─ Step 2. [DESIGN.md] 물리적 판형(196x266mm) 및 미러 마진(홀수 31/26mm, 짝수 27/30mm) 확정
  ├─ Step 3. [STYLE.md] 서체 4중 매핑(한컴바탕/Times), 장평(95%), 자간(-0.5pt), 줄간격 캘리브레이션
  ├─ Step 4. [문서의기본.md] 페이지 넘침 방지 10대 계명 준수 (62p == 62p Zero-Drift 100%)
  ├─ Step 5. OOXML 외과수술 파이프라인 (가짜 표 치환 + 가짜 푸터 척결 + 다단 continuous 고정)
  ├─ Step 6. Hancom COM OLE 연동: 81개 표 전수 TreatAsChar=1 강제 및 139.3mm 리사이징
  └─ Step 7. 트리플 세트 컴파일: DOCX (마스터) ➔ HWP (편집본) ➔ HWPX (개방형 표준)
========================================================================================
                                       ▼ (완벽한 골격 안착 후)
========================================================================================
[2단계: 살아난 문서 위에서 가동되는 한글 원격 제어 (HWP_REMOCON)]
  ├─ Step 8. [HWP_REMOCON.md] Windows COM API (HWPFrame.HwpObject) 헤드리스 원격 연결
  ├─ Step 9. FilePathCheckDLL 보안 승인 모듈 등록 (보안 팝업 0% 완전 차단)
  ├─ Step 10. 표(Table) 셀 내비게이션 (goto_addr) 및 외과수술적 데이터 주입
  ├─ Step 11. 체크박스(□ ➔ ■), 날짜, 서명 캘리브레이션
  ├─ Step 12. 대화형 모달 (ask_question) 연동 본부장님 피드백 및 결손 정보 실시간 수렴
  └─ Step 13. [VERIFY.md] PyMuPDF 300 DPI 래스터라이저 & Multimodal VisionCheck 최종 공인
========================================================================================
```

## 3. 4대 마스터 헌장 문서 (Core Charters)

본 스킬은 어떠한 경우에도 아래 4대 헌장 문서를 무시하고 임의로 작업하는 것을 엄격히 금지합니다:
- **`[DNA.md]`**: 20대 코어 청사진 (조직정체성, 판형, 타이포그래피, 여백, 표, 차트, 각주, 텍스트 전수 통계)
- **`[DESIGN.md]`**: 물리적 판형 치수(Crown Quarto 196.14×265.99mm 등), 미러 마진(홀수 31/26mm, 짝수 27/30mm), 1단/2단 그리드, 배경 데코레이션 배너 안착 규격
- **`[STYLE.md]`**: 서체 4중 매핑(한컴바탕/Times New Roman), 타이포그래피 계층, 장평 95%, 자간 -0.5pt, 줄간격 150%
- **`[문서의기본.md]`**: Zero-Drift 100% 불변의 법칙, 페이지 넘침 방지 10대 계명, 각주 바닥 앵커링, 가짜 푸터 박멸, 목차 연계성

## 4. 3대 기본 탑재 프로토콜 (/plan, /grill-me, /goal)

- **`/plan` (자립 계획 수립)**: 사전 실측 ➔ DNA 확정 ➔ 제1원본(골격) ➔ 본부장님 승인 ➔ 제2원본(본문 주입) ➔ 리모콘 제어 ➔ VisionCheck 전 공정 사전 수립.
- **`/grill-me` (대화형 승인 게이트 & ask_question)**: 골격 완성 시점 및 서식 의심 부분 발생 시 `ask_question` 모달을 통해 본부장님의 재가를 득한 후 후속 단계 진행.
- **`/goal` (0-Error 완결 시까지 연속 추진)**: 단 1글자, 1페이지라도 원본과 다르면 멈추지 않고 스스로 원인을 분석·재조정하여 Zero-Drift 100%를 달성할 때까지 자립 완결.

## 5. 4대 표준 폴더 구조 (Standard Folder Structure)

- **`conversation/`**: 본부장님과의 대화 전체 1:1 무손실 복제 실록 (`CONVERSATION_TOTAL.md`).
- **`prompt/`**: 본부장님의 원천 지시문 영구 보존 (`PROMPT_MASTER.md`).
- **`result/`**: 모든 마스터 스크립트, 문서, 검증 리포트가 `[001]`~`[999]` 순차 번호로 영구 보존되는 유일한 산출물 기지.
- **`upload/`**: 원천 PDF 및 신청서 원본 보관소.
