# vf21-pdf-clone-krei: 차세대 대규모 PDF 100% 무손실 복제 마스터 파이프라인
> **지식재산권자 및 총괄 기획**: (AX)창업기술 이한규 대표  
> **공식 저장소**: `github.com/dansarang99/vf/vf21_pdf_clone_농업전망`  
> **표준 규격**: 20대 코어 청사진(Blueprint) DNA v3.0 & 템플릿 우선배치 2벌식(Two-Draft) 무결성 프로토콜

## 1. 개요 및 설계 철학 (Core Philosophy)

본 스킬은 한국농촌경제연구원(KREI) 농업전망 보고서(37쪽 대형 학술·통계 보고서)를 원본과 **1글자, 1픽셀, 1포인트, 1페이지의 오차도 없이 100% 무손실(Zero-Loss)**로 마이크로소프트 워드(DOCX) 및 완제 PDF로 복제해낸 실제 프로젝트의 모든 기법을 집대성한 마스터 스킬입니다.

기존의 사후 수작업 대조(Post-Conversion Brute-Force)의 한계를 원천 타파하고:
1. **사전 추출 20대 코어 청사진(DNA)**을 기반으로 변환 후 복제본을 **0.1초 만에 기계적으로 전수 린팅(Deterministic Linting)**합니다.
2. `pdf2docx` 오픈소스 엔진의 고질적 결함(차트 캡션 헤더 삭제, 본문 텍스트 내 35개 가짜 푸터 침투, 각주 붕괴, 중복 유령 표 생성)을 **외과수술적 OOXML(OpenXML) 직접 조작**으로 100% 박멸합니다.
3. (AX)창업기술 고유의 **「템플릿 우선배치 2벌식 작업규칙」**을 통해 **제1원본(골격 레이아웃 및 본문 백색 마스킹)**을 먼저 세워 사용자 승인을 득한 후, **제2원본(7,065개 순수 본문 텍스트 흑색 복원)**을 1:1 완제 결합하여 **Zero-Drift(페이지 편차 0%)**를 달성합니다.
4. **MS Word COM OLE 엔진(`win32com.client`)**과 **PyMuPDF(`fitz`)** 듀얼 엔진을 통해 0-Error 무결성을 검증하고, 모든 산출물은 `[001]`부터 `[999]`까지 영구 보존합니다.

### 04. [서체, 글꼴.md] 4중 OOXML 대체 매핑 (핵심 IP)
한컴 폰트 및 비인가 영문 폰트(`Cambria`)로 인한 파편화를 차단하기 위해 OOXML `w:rFonts`를 4대 슬롯에 명시 강제 주입:
```xml
<w:rFonts w:ascii="Times New Roman" 
          w:eastAsia="Batang" 
          w:hAnsi="Times New Roman" 
          w:cs="Times New Roman"/>
```
- 한글: `Batang`(바탕체) 또는 `Malgun Gothic`(맑은 고딕)
- 영문/숫자: `Times New Roman` 또는 `Segoe UI`
- 비인가 영문 폰트(`Cambria`, `Calibri`) 출현율 0건 자동 스캔 룰 적용.

## 3. pdf2docx 5대 엔진 결함 및 외과수술적 극복 솔루션

`pdf2docx`를 이용한 1차 변환 시 발생하는 치명적 버그들을 파이썬 OOXML 외과수술로 완벽하게 해결합니다:

### [결함 1] 차트 캡션 헤더 클리핑 증발 현상 (Chart Header Clipping)
- **원인**: `pdf2docx` 엔진이 이미지/테이블 경계면을 처리할 때 상단 캡션 문단을 이미지 영역으로 오인하여 삭제하거나 이전 페이지 끝으로 밀어내 삭제함.
- **피해**: 4쪽(`| 그림 2-1 | 쌀 생산 추이`), 20쪽(`| 그림 2-10 | 콩 가공 기대점`), 31쪽(`| 그림 2-13 | 감자 출하량`) 상단 헤더 소실.
- **해결 알고리즘**:
  ```python
  # 4쪽 상단 헤더 복원 주입
  for p in doc.paragraphs:
      if '| 표 2-1 |' in p.text:
          new_p = p.insert_paragraph_before('| 그림 2-1 | 최근 10년(2016∼2025년) 쌀 생산 추이(연산 기준)')
          new_p.paragraph_format.space_before = Pt(12)
          new_p.paragraph_format.space_after = Pt(6)
          r = new_p.runs[0]
          r.font.name = 'Batang'
          r.font.size = Pt(9.5)
          r.font.bold = True
          break
  ```

### [결함 2] 본문 내 가짜 푸터 35개 침투 현상 (In-Body Ghost Footers)
- **원인**: `pdf2docx`가 페이지 바닥글을 워드의 섹션 바닥글(`sec.Footers`)로 인식하지 못하고 본문 흐름(`w:body`) 내 일반 텍스트 단락으로 삽입하여, 페이지 중앙이나 단락 사이에 푸터가 둥둥 떠다님.
- **해결 알고리즘**: 정규식을 이용해 본문 내 35개 가짜 푸터를 전수 식별 후 영구 삭제.
  ```python
  footer_re = re.compile(r'^(?:\d+\s*\|\s*제\d+장|\d+\.\s+[가-힣]+\s*\|\s*\d+|\d+\s*\|\s*2024\s*농업전망|부록\s*\|\s*\d+)')
  to_remove = [p for p in doc.paragraphs if footer_re.match(p.text.strip())]
  for p in to_remove:
      p._element.getparent().remove(p._element)
  ```

### [결함 3] 진짜 네이티브 바닥글(sec.Footers) 전면 이관
- 본문에서 삭제된 푸터를 실제 Word 섹션의 `header_footer`로 이관하여 문서 회색 영역에만 표시되도록 조판.

### [결함 4] 각주 붕괴 및 본문 뒤섞임 (Footnote Baseline Collapse)
- **원인**: 각주가 일반 문단으로 취급되어 조판 밀림 유발.
- **해결 알고리즘**: 9대 각주(Page 3, 5, 6, 8, 11, 12, 18, 29, 30)를 식별하여 Word 절대 좌표 프레임(`w:framePr`)을 주입, 페이지 최하단 $Y \approx 653\text{ pt}$ 기준선에 물리적 바닥 앵커링(Anchoring):
  ```python
  pPr = p._element.get_or_add_pPr()
  framePr = OxmlElement('w:framePr')
  framePr.set(qn('w:w'), '7800')
  framePr.set(qn('w:hAnchor'), 'page')
  framePr.set(qn('w:vAnchor'), 'page')
  framePr.set(qn('w:x'), str(int(matched_cfg['x_pt'] * 20)))
  framePr.set(qn('w:y'), str(int(matched_cfg['text_y_pt'] * 20)))
  framePr.set(qn('w:wrap'), 'around')
  pPr.append(framePr)
  ```

### [결함 5] 중복 유령 표(Ghost Table) 생성
- Page 26 등에서 비정상적으로 분할 생성된 미니 표(Table 18 감자 중복 표)를 검출하여 `table._element.getparent().remove(table._element)`로 외과수술적 제거.

## 6. MS Word COM OLE & PyMuPDF 듀얼 엔진 아키텍처

- **MS Word COM OLE (`win32com.client`)**:
  - 타사 라이브러리(LibreOffice 등)의 조판 왜곡을 배제하고, 실제 Microsoft Word 365 엔진을 무인 백그라운드(`word.Visible = False`, `word.DisplayAlerts = 0`)로 구동하여 PDF로 100% 네이티브 컴파일(`SaveAs(FileFormat=17)`).
- **PyMuPDF (`fitz`)**:
  - 컴파일된 PDF의 37페이지 전수 글자 수 카운팅, 위경도 좌표 실측, 150/200/300 DPI 비주얼 프루프(Proof) 자동 생성.

## 8. 사용법 및 트리거 가이드

사용자가 대규모 학술/통계 PDF 문서(농업전망, 국책연구보고서 등) 복제를 요청하거나, PDF-to-Word 변환 시 페이지 밀림(Page Drift) 문제를 제기할 때 본 스킬을 활성화하여 다음 순서로 실행합니다:
1. `python process/build_draft1_skeleton.py` : 제1원본 골격 및 배너 안착
2. `python process/execute_master_043_to_046_clean.py` : 엔진 버그 외과수술 및 바닥 각주/네이티브 푸터 정립
3. 사용자에게 제1원본 PDF 및 검증보고서 제출 후 공식 승인 대기
4. 승인 후 `python process/build_draft2_master_047_to_050.py` : 본문 텍스트 7,065개 런 100% 흑색 복원
5. PyMuPDF 0.1초 린터 구동으로 Zero-Drift 100% 및 0-Error 무결성 공식 판정.
