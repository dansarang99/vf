# 제1장. 총론 및 패러다임 전환

기존의 문서 변환은 변환 후 사람이 페이지를 넘겨보며 오탈자를 찾거나 원본과 복제본을 시각적으로 1:1 대조하는 **사후 수작업 대조(Post-Conversion Brute-Force)**에 머물렀습니다. 이는 방대한 시간과 집중력을 소모할 뿐만 아니라, `Page 1 저자 각주 1줄 누락`, `Page 31 차트 공란화`, `책자 인덱스 탭 누락`과 같은 외곽 결손을 놓치는 구조적 한계가 있었습니다.

본 교과서가 정립하는 **(AX)창업기술 마스터 검증 체계**는 변환 전 원본 문서로부터 **19대 핵심 DNA**를 기계적으로 사전 추출하여 `DOCUMENT_DNA.json`으로 확정하고, 변환된 워드(DOCX) 문서를 이 명세서와 **0.1초 만에 기계적으로 맞비교하여 100% 무결성을 판정**하는 사전 예방형 품질 보증 시스템입니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│                   19대 사전 검증 패턴 기반 마스터 변환 파이프라인       │
├────────────────────────────────────────────────────────────────────────┤
│  [원본 문서] ➔ (1. 사전 DNA 추출기) ➔ [19대 청사진 DOCUMENT_DNA.json]   │
│       │                                          │                     │
│  (2. 외과수술 변환)                               │ (기준선 잠금)       │
│       ▼                                          ▼                     │
│  [복제 워드문서] ➔ (3. 0.1초 오토 린터) ➔ [PASS / FAIL 정량 감사 보고서] │
└────────────────────────────────────────────────────────────────────────┘
```

## Part I. 비즈니스 및 시각 기하학 골격 (Modules 01 ~ 06)

### 01. [businessDNA.md] 조직 정체성 및 지식재산권
- **사전 추출 패턴**:
  - 문서 성격 식별자: `[Academic/Research Report]` vs `[Enterprise ISO Manual]`
  - 원천 조직 및 저자 인벤토리: 한국농촌경제연구원(KREI), 박한울, 김다정, 최준혁, 김지훈 등 전원 목록 및 이메일.
  - 지식재산권 표기: `(AX)창업기술 이한규 대표` 마스터 파이프라인 메타데이터.
- **자동 검증 룰**: `assert len(extracted_authors) == 4`, `assert target_company_brand_applied == True`.

### 02. [DESIGN.md] 판형, 그리드 및 컨테이너 아키텍처
- **사전 추출 패턴**:
  - 판형 실측치: `196.1mm × 266.0mm` (556.0 × 754.0 pt, Crown Quarto 4×6배판 변형).
  - 특수 컨테이너: Page 2 `요약` 라운드 사각형 카드 여부, 표지 풀블리드 배경 여부.
- **자동 검증 룰**: `w:pgSz w:w="11120" w:h="15080"` 0.1mm 오차 이내 일치, 컨테이너 왜곡 0건.

### 03. [STYLE.md] 시각 스타일 토큰 및 컬러 팔레트
- **사전 추출 패턴**:
  - 표 헤더 음영: `#D5DBE0`
  - 요약 카드 배경: `#F5F6F8`
  - 브랜드 포인트: `#0099CC`, 강조 레드: `#FF3300`, 캡션/머리글 회색: `#717171`
  - 표 테두리: 상하 굵은선(1.5pt), 내부 얇은선(0.5pt), 좌우 무테두리.
- **자동 검증 룰**: 표 셀 음영(`w:shd w:fill="D5DBE0"`) 정합률 100%.

### 04. [Typography.md] 폰트 패밀리 및 서체 위계 계단
- **사전 추출 패턴**:
  - 폰트 듀얼 매핑: 제목 고딕 ➔ `맑은 고딕(Bold)`, 본문 바탕 ➔ `바탕체`, 숫자/영문 ➔ `Times New Roman`.
  - 위계 계단: 장제목(22pt) > 절(15pt) > 소제목(14pt) > 본문(10.5pt) > 각주(7pt).
- **자동 검증 룰**: 본문/제목 폰트 오적용 0건, 비인가 영문 폰트(`Cambria`) 침투 0건.

### 05. [상하좌우 여백.md] 섹션 판면 규격 및 인쇄 바운딩 박스
- **사전 추출 패턴**: 상단(20mm), 하단(22mm), 좌측(22mm), 우측(22mm), 머리글(12mm), 바닥글(12mm). 1p 표지 사방 0mm.
- **자동 검증 룰**: 모든 섹션의 `w:pgMar` 값이 기준치와 100% 일치할 것.

### 06. [장평,자간,줄간격(상하).md] 미세 타이포그래피 정합 공식
- **사전 추출 패턴**: 장평 `95%` (`w:w="95"`), 자간 `-0.5pt` (`w:spacing="-10"`), 줄간격 `160%` (`w:line="384"`), 단락 전후 여백.
- **자동 검증 룰**: 37개 전 페이지의 Head(첫 20자) 및 Tail(끝 20자) 텍스트 앵커가 원본과 100% 일치할 것.

## Part II. 정보 개체 및 미디어 에셋 (Modules 07 ~ 10)

### 07. [표(table).md] 표 구조, 테두리, 수치 무결성 체크섬
- **사전 추출 패턴**: 표 29개(본문 25개 + 부록 4개) 전수 인벤토리, 2단 헤더 구조, 행/열 차원.
- **수치 무결성 체크섬**: 표 내 모든 숫자 셀을 추출하여 합산한 해시값 (예: `Table_2_1_Sum = 2276.8`).
- **자동 검증 룰**: 수치 체크섬 100% 일치 (데이터 변조 0%), 빈 테두리 유령 표(Ghost Table) 생성 0건.

### 08. [그래프.md] 고해상도 인포그래픽, 배치 순서 앵커, 출처
- **사전 추출 패턴**: 차트 13종(그림 2-1~2-13) 전수 바운딩 박스 및 300 DPI 무손실 래스터 크롭 에셋.
- **상대 순서 앵커**: Page 4(차트 < 표), Page 16(표 < 차트).
- **자동 검증 룰**: 차트 누락 0건 (`assert len(charts) == 13`), Page 31 감자 차트 공란화 0건, 배치 역전 0건.

### 09. [데코레이션.md] 디자인 그래픽, 배경 아트워크, 책자 인덱스 탭 (신규 탑재)
- **왜 필수적인가?**: 데이터 차트가 아닌 **디자인 목적으로 삽입된 시각 에셋**은 변환 시 가장 먼저 삭제되거나 타일링 줄눈이 발생함.
- **사전 추출 패턴**:
  - 표지 배경 풀블리드 지구본 망 아트워크 (Seam Gap 발생 방지)
  - 책자 우측 날개 인덱스 탭 (`제1장`~`제5장`, 활성 탭 하이라이트)
  - Page 2 `요약` 상단 다크그레이 캡슐형 악센트 바
  - 장/절 타이틀 배지 (`| 제2장 |`, `부록3` 그레이 박스)
  - 헤더 KREI 로고 및 코너 라운드 프레임 선
- **자동 검증 룰**:
  - 1차 변환에서 누락되었던 **204개 데코레이션 에셋 복원율 100%**.
  - 배경 이미지 타일링에 의한 가로 흰색 줄눈(Seam Gap) 0건 검증.

### 10. [미주/각주/참조자료.md] 본문 인라인 첨자 및 각주 1:1 매핑 쌍
- **사전 추출 패턴**: 본문 내 윗첨자(`1)`, `2)`, `3)`) 위치 및 개수, 하단 각주 설명문 리스트.
- **1:1 결합 공식**: $\text{Count}(\text{본문 첨자}) \equiv \text{Count}(\text{하단 각주 설명문})$.
- **자동 검증 룰**: `pdf2docx` 겹침 오류로 인한 **Page 1 제1저자 각주 삭제 현상 원천 차단**.

## Part III. 구조 및 기능 엔지니어링 (Modules 11 ~ 15)

### 11. [다단 및 섹션 분할.md] 다단 혼합 판면 및 연속 구역 나누기
- **사전 추출 패턴**: 1단(초록/표) ➔ 2단(본문) 컬럼 수, 단 간격, 연속형 구역 나누기(`w:type="continuous"`).
- **자동 검증 룰**: 2단 문서를 억지 단일 셀 표로 변환하는 왜곡 차단, 네이티브 `w:cols` 섹션 검증.

### 12. [수식(Equation).md] MathML / OMML 네이티브 수식 구조
- **사전 추출 패턴**: KASMO 전망 수리모형 수식 블록 개수, LaTeX/MathML 표현식, 수식 번호.
- **자동 검증 룰**: 찌그러진 비트맵 수식 퇴출, 워드 네이티브 `<m:oMath>` 수식 객체 탑재율 100%.

# 제3장. 통합 검증 실행 알고리즘 (0.1초 Automated Linting)

19대 모듈은 변환 전 단 한 번의 실행으로 `DOCUMENT_DNA.json`으로 컴파일되며, 변환 완료 후 파이썬 기반 `dna_verifier.py`가 이를 로드하여 **0.1초 만에 전수 검증**합니다.

# (AX)창업기술 19대 청사진 마스터 자동 린터 로직
def verify_document_19_dna(docx_path, dna_manifest_path):
    dna = load_json(dna_manifest_path)
    audit = {"PASS": [], "FAIL": []}
    
    # 1. 기하학 & Zero-Drift 검증 (37p == 37p)
    actual_pages = get_word_rendered_pages(docx_path)
    assert actual_pages == dna["DESIGN"]["total_pages"], "Page Drift FAIL"
    
    # 2. 19대 모듈 린팅 (표 체크섬, 차트 배치, 데코레이션, 각주 등)
    check_business_dna(docx_path, dna["businessDNA"], audit)
    check_decorations(docx_path, dna["DECORATION"], audit)       # Module 09 신규
    check_tables_checksum(docx_path, dna["TABLES"], audit)       # Module 07
    check_charts_order(docx_path, dna["CHARTS"], audit)          # Module 08
    check_footnotes_pair(docx_path, dna["FOOTNOTES"], audit)     # Module 10
    check_dynamic_page_fields(docx_path, dna["FIELDS"], audit)   # Module 14
    check_sanitized_metadata(docx_path, dna["METADATA"], audit)  # Module 17
    
    # 3. 정량적 일치율 산출
    score = len(audit["PASS"]) / (len(audit["PASS"]) + len(audit["FAIL"])) * 100.0
    return score, audit
