# 템플릿 우선배치 2벌식 작업규칙 (Two-Draft Protocol)
> **지식재산권자**: (AX)창업기술 이한규 대표  
> **철칙**: "내가 승인할 때까지는 실행하면 안 됨. 승인 뒤에 실행된 결과를 내놓는 것이 제대로 된 순서임. 절대 앞서가지 말 것."

---

## 1. 개요 및 워크플로우

대규모 문서 복제에서 본문 텍스트와 레이아웃 골격을 한 번에 변환하면 문단 넘침과 줄바꿈으로 인해 레이아웃이 붕괴됩니다.
(AX)창업기술은 이를 원천 차단하기 위해 **제1원본(골격 레이아웃)**과 **제2원본(본문 텍스트 결합본)**을 엄격히 분리하여 수행합니다:

```
┌────────────────────────────────────────────────────────┐
│  제1단계: 제1원본 (Draft 1) - 골격 레이아웃             │
│  - 본문 서사 단락 텍스트 백색(FFFFFF) 공백 슬롯 마스킹 │
│  - 6대 300 DPI 대형 표제면 배너 안착                   │
│  - 35개 본문 가짜 푸터 삭제 & 네이티브 바닥글 이관     │
│  - 9대 각주 페이지 바닥 프레임(Y≈653pt) 고정           │
│  - 18개 표 외곽선 및 13종 차트 300 DPI 에셋 우선 배치  │
│  - 산출물: [043] DOCX, [044] PDF, [045] 원인규명보고서 │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│  제2단계: 사용자 검증 및 확인 게이트 (User Sign-off)   │
│  - 제1원본의 골격 배치 및 여백 기준선을 사용자에게 보고│
│  - 사용자 공식 승인 획득 시까지 제2단계 착수 절대 금지  │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│  제3단계: 제2원본 (Draft 2) - 본문 텍스트 1:1 완제 결합│
│  - 골격이 확정된 제1원본의 공백 슬롯을 호출            │
│  - 사전 수집된 7,065개 순수 본문 텍스트 런 주입        │
│  - 색상을 순수 흑색(000000)으로 1:1 전면 복원         │
│  - 산출물: [047] DOCX, [048] PDF                      │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│  제4단계: 0.1초 기계적 전수 감사 (Automated Linting)   │
│  - PyMuPDF 기반 37페이지 전수 글자 수 계측             │
│  - Zero-Drift 100% (37/37 페이지 정확 유지) 판정       │
│  - 산출물: [049] 정밀검증보고서, [050] 통합 감사보고서 │
└────────────────────────────────────────────────────────┘
```
